# Disquiet (디스콰이엇) 프로젝트 소개

대상: disquiet.io
형식: 프로젝트 등록 (메이커 계정으로 직접 등록)
성격: 한국 메이커 커뮤니티. 자기 제품 자랑보다 "왜 만들었고 뭐가 어려웠는지"에 반응이 좋습니다. 링크 클릭보다 실제 사용 후기가 남는 채널입니다.

## 한 줄 소개 (60자 이내 권장)

```
긴 영상에서 가장 강한 순간만 골라 16:9 하이라이트 하나로 만들어 주는 브라우저 앱
```

## 카테고리 · 태그

- 카테고리: **영상 · AI**
- 태그: `AI`, `영상편집`, `하이라이트`, `브라우저`, `사이드프로젝트`

## 소개 본문

```
찍어 두고 한 번도 다시 안 본 영상이 많았습니다.

여행 다녀와서 찍은 30분, 웨딩 원본 2시간, 주말 경기 녹화 90분. 편집 앱을 열면 컷 고르는 데만 한 시간이 걸리고, 그 시간이 아까워서 결국 안 건드리게 됩니다.

그래서 "고르는 일"을 AI에 넘기고, 사람은 "확인하고 다듬는 일"만 하도록 만들었습니다.

1. 영상을 브라우저에 올리면 프레임을 일정 간격으로 샘플링합니다.
2. 샘플 프레임을 비전 모델로 분석해 극적인 구간 후보를 뽑습니다.
3. 영상마다 1~3개의 결정적 구간을 골라 1.5~4.5초 단위로 정리합니다. 겹치는 구간은 제거합니다.
4. 사용자는 컷을 보고 자르거나 순서를 바꿉니다.
5. 인트로·날짜/장소 전환·아웃트로·배경음악·자막을 붙여 16:9 하나로 렌더링합니다.

원본 영상은 서버로 올라가지 않습니다. 분석에 쓰는 건 브라우저에서 뽑은 소량의 프레임이고, 최종 렌더링도 브라우저에서 돌립니다. 그래서 서버 비용이 영상 길이에 비례하지 않고, 무료 모델을 기본으로 제공할 수 있습니다.

만들면서 가장 오래 붙잡았던 건 렌더링이었습니다. Canvas + MediaRecorder + Web Audio로 컷을 이어 붙이면 구간 경계에서 오디오가 끊기고 프레임이 한 장씩 튀었습니다. 경계마다 오디오 버퍼를 이어 붙이고, 컷 시작 프레임을 고정한 뒤에야 결과물이 자연스러워졌습니다.

지금은 16:9만 지원합니다. 세로로 찍은 원본은 인물 위치를 보고 16:9로 크롭하지만, 쇼츠·릴스용 세로 결과물은 자막과 크롭 레이아웃을 다시 설계해야 해서 다음 과제로 두었습니다.

7개 언어(한국어·영어·일본어·중국어·스페인어·프랑스어·독일어)를 지원하고, 기본 AI 모델은 무료입니다.

https://penguincut.com
```

## 메이커 코멘트 (첫 댓글)

```
만든 사람입니다. 처음엔 컷을 많이 뽑아 주면 좋겠다고 생각했는데, 실제로 써 보니 20~30개 중에 진짜 쓸 건 두세 개더군요. 그래서 영상 하나당 1~3구간만 고르게 바꿨습니다. 대신 인트로·브릿지·아웃트로를 붙여서 결과물이 "짧은 클립 모음"이 아니라 한 편의 영상처럼 보이게 했습니다.

이 방향이 맞는지 궁금합니다. 컷이 더 많았으면 좋겠는지, 아니면 지금처럼 적고 강한 쪽이 좋은지 알려 주세요. 그리고 어떤 영상으로 써 보셨는지도요.
```
