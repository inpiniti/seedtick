# GeekNews 소개 글

대상: news.hada.io (GeekNews)
형식: **Show GN** — 자기 프로젝트를 소개하는 정식 태그입니다.
성격: 개발자 커뮤니티. 과장된 마케팅 문구는 반드시 지적받습니다. 만든 이유와 동작 원리를 솔직하게 쓰는 쪽이 훨씬 좋게 반응합니다.

## 제목 (하나 선택)

1. `Show GN: PenguinCut – 긴 영상을 16:9·9:16 하이라이트로 만들어 주는 브라우저 앱`
2. `Show GN: 영상 편집을 안 하려고 만든 AI 하이라이트 에디터 (100% 브라우저 렌더링)`

1번이 검색 유입에 유리하고, 2번이 클릭률에 유리합니다. 첫 게시는 1번을 권장합니다.

## 본문

```
안녕하세요. 긴 영상에서 하이라이트만 뽑아 주는 브라우저 앱 PenguinCut을 만들었습니다.

여행 영상 30분, 웨딩 원본 2시간, 경기 녹화 90분 — 찍어 두고 한 번도 다시 안 본 파일이 쌓여 있었습니다. 편집 앱을 열고 컷을 고르는 과정이 귀찮아서, "가장 강한 순간 몇 개만 골라 16:9 또는 9:16 하이라이트로 붙여 주는" 도구를 만들었습니다.

동작 방식
1. 브라우저에서 영상의 프레임을 일정 간격으로 샘플링합니다. 원본 파일은 업로드하지 않습니다.
2. 샘플 프레임을 비전 모델에 보내 극적인 구간 후보를 JSON으로 받습니다.
3. 영상마다 1~3개의 결정적 구간을 받고, 각 구간을 1.5~4.5초로 제한하고 겹침을 제거해 컷 리스트로 만듭니다.
4. 사용자가 컷을 검토하고 자르거나 순서를 바꾼 뒤, Canvas + MediaRecorder + Web Audio로 브라우저에서 렌더링합니다.
5. 인트로, 날짜·장소 전환 브릿지, 아웃트로, 배경음악, 자막까지 한 번에 붙습니다.

기술적으로 신경 쓴 부분
- 원본 영상은 기기에 남습니다. 서버로 가는 건 샘플 프레임과 메타데이터뿐입니다.
- Vercel 서버리스의 4.5MB 요청 제한 때문에, 분석용 프레임을 캔버스에서 초경량으로 다시 샘플링합니다.
- 렌더링도 브라우저에서 하므로 서버 비용이 영상 길이에 비례하지 않습니다. 대신 긴 영상은 기기 성능을 탑니다.
- 7개 언어(한국어·영어·일본어·중국어·스페인어·프랑스어·독일어)를 지원합니다.

가격
기본 제공되는 AI 모델은 무료로 쓸 수 있고, 다른 모델을 쓰고 싶으면 자기 API 키를 연결할 수 있습니다.

한계도 있습니다
- 1시간 넘는 영상은 프레임 샘플링에 시간이 꽤 걸립니다.
- AI 컷은 짧게 나옵니다. 영상 하나당 1~3구간, 합쳐서 10초 안쪽이라 인트로·브릿지·아웃트로를 붙여 완성합니다. 많이 뽑는 게 아니라 가장 강한 것만 남기는 쪽을 택했습니다.
- 포맷은 새 프로젝트를 시작할 때 16:9 또는 9:16으로 고릅니다. 한 프로젝트에서 두 포맷을 동시에 뽑지는 않고, 9:16에서는 플랫폼별 안전 영역에 맞춰 자막과 크롭을 배치합니다.
- AI가 고른 컷이 항상 정답은 아니어서, 검토 화면에서 직접 손보는 걸 전제로 만들었습니다.

https://penguincut.com
```

- GeekNews는 자기 홍보를 허용하지만, **첫 댓글에 링크를 또 도배하거나 홍보를 반복하면** 반감을 삽니다. 질문에 답하는 데 집중하세요.
- 게시 후 2~3시간은 댓글을 계속 확인할 수 있는 시간대에 올리는 게 좋습니다. 평일 오전 10시~11시(한국 시간)가 무난합니다.
