## 공통 원칙

카피를 쓸 때 지킨 것:

- **"무료"는 "무료 AI 모델 포함"으로 씁니다.** 영구 무료를 약속하지 않습니다.
- **"업로드 없음"은 "원본 파일은 기기에 남음"으로 씁니다.** 분석용 샘플 프레임은 전송되므로 "아무것도 전송 안 함"은 거짓입니다.
- **과장 금지.** revolutionary, game-changing, 10x 같은 표현은 쓰지 않습니다. 개발자 커뮤니티에서 역효과입니다.
- **숫자는 확인된 것만.** 7개 언어, 16:9, 36초 데모, 브라우저 렌더링 — 전부 실제 동작 기준입니다.
