# Subscription & Auth 기능 명세 (feature.md)

## 1. 회원 인증 (Supabase Auth)
- **카카오 간편 로그인**: 카카오 OAuth 2.0 연동으로 1초 가입 및 로그인.
- **구글 간편 로그인**: 구글 계정을 통한 원클릭 로그인.
- **이메일 매직링크 / OTP**: 소셜 연동을 원치 않는 사용자를 위한 이메일 인증 로그인.
- **프로필 동기화**: 로그인 성공 시 `user_profiles`에 정보가 자동 생성/업데이트되고 기본 Free 구독 정보가 부여됨.

## 3. 리포트 날짜 선택 및 권한 제어 유스케이스

### UC-1: 날짜 선택 드롭다운 진입 시
1. Free 유저가 주식 상세/카탈로그에 진입할 때:
   - 시스템은 현재 일자 기준 30일 이전의 보고서 일자 중 가장 최신 날짜를 디폴트로 자동 선택한다.
2. Pro 유저는 시스템상 가장 최신 보고서 발행일이 디폴트로 선택된다.

### UC-2: Free 유저가 최근 1개월(30일) 이내 날짜 클릭 시
1. 날짜 선택기에서 최근 30일 이내 날짜(Pro 전용 배지 표시)를 클릭한다.
2. 즉시 변경되지 않고 **"SeedTick Pro 전용 콘텐츠" 안내 모달**이 팝업된다.
   - 모달 내용: "최근 1개월간 발행된 최신 13인 거장 AI 리서치 보고서는 Pro 회원 전용입니다."
   - 버튼 1: `취소` -> 기존 과거 날짜 상태를 유지하고 팝업을 닫음.
   - 버튼 2: `Pro 시작하기 (월 2,900원)` -> 요금제 결제 화면 또는 결제 모달로 이동.

## 4. 결제 및 구독 라이프사이클 (PortOne V2)

### UC-3: 결제 플랜 선택 및 결제창 호출
1. 사용자가 요금제 모달에서 플랜을 선택한다:
   - **월간 정기 플랜 (2,900원/월)**: 신용카드 등록(빌링키 발급) 방식으로 포트원 결제창 연동.
   - **연간 플랜 (29,000원/연, 2개월 무료)**: 카드 정기 결제 또는 단건 결제(카드/카카오페이 등).
2. 결제 완료 시:
   - 포트원 결제 승인 응답 및 서버사이드 검증.
   - DB `subscriptions`의 `tier`를 `'pro'`로 갱신, `current_period_end`를 계산하여 저장.
   - 즉시 세션 상태가 Pro로 전환되어 최근 1개월 보고서가 잠금 해제됨.

### UC-4: 구독 해지
1. Pro 사용자가 프로필/구독 설정에서 "구독 해지"를 클릭.
2. `subscriptions.status`가 `'canceled'`로 변경되어 다음 주기 자동 결제는 예약 취소됨.
3. 현재 마감일(`current_period_end`)까지는 Pro 혜택이 계속 유지된다.
