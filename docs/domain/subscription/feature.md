# Subscription & Auth 기능 명세 (feature.md)

## 1. 회원 인증 (Supabase Auth)
- **구글 간편 로그인**: 구글 계정을 통한 원클릭 로그인.
- **이메일 매직링크 / OTP**: 이메일 인증 로그인.
- **프로필 동기화**: 로그인 성공 시 `user_profiles`에 정보가 자동 생성/업데이트되고 기본 Free 구독 정보가 부여됨.

## 3. 리포트 날짜 선택 및 권한 제어 유스케이스

### UC-1: 비로그인 사용자가 최신 리포트/잠금 콘텐츠 클릭 시
1. 비로그인 유저가 카탈로그나 주식 상세에서 최신 리포트 날짜나 잠금 카드를 클릭한다.
2. 유료 결제 모달이 아닌 **"로그인하고 24시간 무료로 보기" 웰컴 모달**이 오픈된다.
   - 문구: "회원가입 시 24시간 동안 모든 최신 13인 거장 AI 리서치 보고서를 무료로 열람하실 수 있어요."
   - 버튼: `Google로 계속하기` (간편 로그인 유도)
   - 버튼 2: `과거 무료 보고서 먼저 둘러보기` (닫기)

### UC-2: 신규 가입 유저의 24시간 무료 체험 유스케이스
1. 가입 성공 시점(`created_at`)부터 24시간 동안 `isWelcomeTrialActive = true`로 판정된다.
2. 헤더 및 리포트 상단에 `🎁 24시간 무료 체험 중` 배지와 잔여 시간(예: "18시간 남음")이 표시된다.
3. 최신 리포트와 최근 1개월 보고서가 잠금 없이 즉시 열람되며, 디폴트 날짜도 최신 발행일로 자동 지정된다.
4. 리포트 본문 상단에 토스 스타일의 따뜻한 안내 배너 노출:
   - "첫 방문 선물! 24시간 동안 모든 최신 거장 리포트를 마음껏 열람하실 수 있어요."

### UC-3: 24시간 체험 만료 후 (일반 Free 유저) 최신 리포트 클릭 시
1. 가입 후 24시간이 경과한 유저는 일반 Free 티어로 전환된다.
2. 최근 30일 이내 날짜를 클릭하면 **"체험 종료 및 Pro 업그레이드" 안내 모달**이 오픈된다.
   - 문구: "어제 무료 체험은 어떠셨나요? 매일 실시간으로 업데이트되는 13인 거장 AI 리포트를 계속 받아보시려면 Pro로 시작해보세요."
   - 버튼: `Pro 시작하기 (월 2,900원 / 하루 96원)`

## 4. 결제 및 구독 라이프사이클 (PortOne V2)

### UC-3: 결제 플랜 선택 및 결제창 호출
1. 사용자가 요금제 모달에서 플랜을 선택한다:
   - **월간 정기 플랜 (2,900원/월)**: 신용카드 등록(빌링키 발급) 방식으로 포트원 결제창 연동.
   - **연간 플랜 (29,000원/연, 2개월 무료)**: 카드 정기 결제 또는 단건 결제(카드/카카오페이 등).
2. 결제 완료 시:
   - 포트원 결제 승인 응답 및 서버사이드 검증.
   - DB `subscriptions`의 `tier`를 `'pro'`로 갱신, `current_period_end`를 계산하여 저장.
   - 즉시 세션 상태가 Pro로 전환되어 최근 1개월 보고서가 잠금 해제됨.

### UC-4: 구독 해지 (청약철회 7일 정책)
1. Pro 사용자가 멤버십 관리(`/account`)에서 "구독 해지"를 클릭하면, 확인 시트에서 처리 결과(환불 금액 또는 이용 종료일)를 미리 보여준다.
2. 확정 시 클라이언트는 `POST /api/billing/cancel`을 호출하고, 서버가 포트원 API를 호출한다.
   - **결제 후 7일 미만**: `POST /payments/{paymentId}/cancel` 전액 환불 → 구독 즉시 만료, 결제 내역 `refunded`.
   - **7일 이후**: `DELETE /billing-keys/{billingKey}`로 자동결제 차단 → `status = 'canceled'`, `current_period_end`까지 Pro 유지.
3. 포트원 호출이 실패하면 DB 상태를 바꾸지 않고 에러 토스트를 보여준다.
4. `PORTONE_API_SECRET` 미설정 또는 테스트 결제 ID(`_test_`)이면 서버는 시뮬레이션 성공으로 응답한다.

### UC-5: 멤버십 관리 화면 (`/account`)
- 진입: 헤더의 `PRO MEMBER` / `TRIAL MEMBER` 검정 배지, 또는 프로필 드롭다운의 "멤버십 관리".
- **Pro**: 플랜(월/연), 상태(이용 중/해지 예약됨), 남은 일수, 다음 결제일 또는 이용 종료일, 결제 수단(카드 끝 4자리), 결제 내역(일자·플랜·금액·상태·영수증), 해지 버튼.
- **Trial**: 체험 남은 시간 + "PRO 시작하기" CTA.
- **Free**: Free 안내 + "PRO 시작하기" CTA, 과거 결제 내역이 있으면 표시.
- 비로그인: 로그인 유도.
