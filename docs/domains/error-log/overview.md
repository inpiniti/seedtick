# Error-Log 도메인 개요

## 역할

시스템 전체에서 발생하는 에러를 수집하고 Discord 웹훅으로 알림을 발송합니다.

## 알림 레벨

| 레벨 | 설명 | 알림 여부 |
|:---|:---|:---:|
| `INFO` | 정상 이벤트 (배치 완료 등) | 선택적 |
| `WARNING` | 주의 이벤트 (일부 실패, 재시도) | O |
| `ERROR` | 에러 (매매 실패, 분석 실패) | O (즉시) |
| `CRITICAL` | 심각한 에러 (키 소진, 인증 실패) | O (즉시) |
