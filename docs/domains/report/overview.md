# Report 도메인 개요

## 역할

종목 티커(미국 주식)를 입력받아, 결정론적 데이터팩 빌더로 공용 심층 팩트를 수집하고, 13인의 투자 거장 페르소나 요약 → 최종 종합 투자 보고서를 산출하며 Supabase DB에 동기화합니다. 13인 요약의 쟁점·적정가·표결은 마스터 단계에서 직접 교차검증합니다.
(참고: `financial/.claude/skills/guru-report` 스펙 정본 준수)

## 4단계 파이프라인

```text
[티커]
  │
  ▼
[1단계] 공용 심층 데이터 팩 생성 (DataPackBuilder: Yahoo, SEC, Toss)
  │      └─ docs/report/{날짜}/_data/{티커}.md
  ▼
[2단계] 13인 개별 요약 블록 생성 (AI-Gateway 키 로테이션 활용 최대 10개 세마포어 동시 병렬 처리)
  │      └─ docs/report/{날짜}/_data/{티커}_요약.md
  ▼
[3단계] 최종 종합 투자 보고서 생성 (핵심 쟁점·적정가 밴드·판정·Bull/Bear·실전 가이드)
  │      └─ docs/report/{날짜}/최종/{티커}_최종보고서.md
  │      └─ 13인 요약을 직접 대조해 최종 판정(verdict/score)을 도출
  ▼
[4단계] Supabase DB 동기화 (guru_reports 및 guru_votes 테이블 기록) & 알림
```

## 산출물 디렉터리 구조

모든 산출물은 웹 앱 뷰어 및 사용자 확인을 위해 일자별 마크다운 파일로 보존됩니다:
```text
docs/report/{YYYY-MM-DD}/
├── _data/
│   ├── {티커}.md           # 1단계: 정량/정성 공용 데이터팩
│   └── {티커}_요약.md      # 2단계: 13인의 개별 요약 블록
└── 최종/
    └── {티커}_최종보고서.md # 3단계: 최종 마스터 종합 투자 보고서
```

## 13인의 거장 페르소나

| # | 페르소나 | 투자 철학 및 핵심 기준 |
|---|:---|:---|
| 1 | 벤저민 그레이엄 (Benjamin Graham) | 절대적 안전마진, 순유동자산(NCAV), 저PER·저PBR |
| 2 | 세스 클라먼 (Seth Klarman) | 원금 보존 최우선, 절대 안전마진, 비유동성 할인 |
| 3 | 모니시 파브라이 (Mohnish Pabrai) | 단도 투자(Dhandho), 큰 업사이드 작은 다운사이드 |
| 4 | 조엘 그린블라트 (Joel Greenblatt) | 마법공식 (높은 자본수익률 ROC + 높은 이익수익률 EY) |
| 5 | 앙드레 코스톨라니 (André Kostolany) | 코스톨라니의 달걀 모델, 시장 심리와 유동성 |
| 6 | 잭 슈웨거 (Jack Schwager) | 추세추종, 손익비(Risk/Reward), 손절선 철저 준수 |
| 7 | 워런 버핏 (Warren Buffett) | 경제적 해자, 높은 ROE, 훌륭한 비즈니스 적정가 매수 |
| 8 | 필립 피셔 (Philip Fisher) | 15개 스커틀벗 질문, 장기 성장 잠재력, R&D 역량 |
| 9 | 찰리 멍거 (Charlie Munger) | 역발상, 롤라팔루자 효과, 다학제적 격자틀 모델 |
| 10 | 피터 린치 (Peter Lynch) | PEG 비율, 6대 기업 분류, 아는 것에 투자 |
| 11 | 애스워스 다모다란 (Aswath Damodaran) | DCF 현금흐름할인, 스토리와 넘버의 결합, 내재가치 |
| 12 | 존 템플턴 (John Templeton) | 극도의 비관론 시점 매수, 글로벌 바겐헌팅 |
| 13 | 마이클 버리 (Michael Burry) | 재무제표 각주 검증, 비대칭 다운사이드 프로텍션 |

보고서 생성은 위 13개 페르소나를 단일 roster로 사용한다. 스크리너용 `뉴욕주민` 항목은 보고서에서 별도 14번째 인원으로 세지 않으며, 공식 g9의 찰리 멍거와 중복 집계하지 않는다. 공식 표결과 요약표는 같은 roster 순서를 공유한다.

최종 의견은 13인 중 최소 12개의 유효 응답을 받은 경우에만 채택하며, 한 의견이 유효 표의 60% 이상일 때 그 의견을 쓴다. 그 외에는 관망이다. 기본값과 파싱 실패는 유효 응답에서 제외한다.

적정가는 각 유효 가격 구간 중점값의 중앙값으로 집계한다. Q1–Q3는 중앙 50% 가격 구간으로 표시하며, 가격 의견 분산율은 이상치에 강건한 사분위 범위(IQR / 중앙값)로 산출한다. 극단적 이상치가 있더라도 로버스트 통계량인 중앙값·밴드·실행 가격을 온전히 보존하며, 분산율이 높을 경우 검토 플래그로 안내한다. 이전 보고서 가격에 결과를 맞추지 않는다.

보고서 전용 모델과 temperature를 고정해 한 보고서 안에서 모델이 섞이지 않게 한다. `avg_confidence`는 페르소나가 스스로 응답한 확신도 평균이며 실제 정확도나 표결 일치도를 뜻하지 않는다. 표결 일치도와 가격 분산은 별도 지표다.
