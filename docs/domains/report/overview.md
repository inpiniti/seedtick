# Report 도메인 개요

## 역할

종목 ticker를 받아서, LLM을 통해 투자자 페르소나 분석을 수행하고, 최종 매수/매도/관망 판단이 담긴 리포트를 생성합니다.

## 책임 범위

- 종목 재무 데이터 수집 (Yahoo Finance)
- LLM 프롬프트 생성 (페르소나 기반)
- AI-Gateway 호출 (OpenAI 규격)
- LLM 응답 파싱 → Report 객체 생성
- 생성된 Report를 Supabase에 저장

## 페르소나 목록 (기본값)

| 페르소나 | 투자 철학 |
|:---|:---|
| 워런 버핏 | 내재가치, 안전마진, 장기 보유 |
| 마이클 버리 | 역발상, 가치주, 거품 경계 |
| 모니시 파브라이 | 비대칭 베팅, 클론 투자 |
| 벤저민 그레이엄 | 안전마진 엄격, 정량 분석 |
| 세스 클라먼 | 절대 안전마진, 현금 선호 |
| 앙드레 코스톨라니 | 시장 심리, 대중과 반대 |
| 애스워스 다모다란 | DCF, 내재가치 계산 |
| 잭 슈웨거 | 기술적 분석, CAN SLIM |
