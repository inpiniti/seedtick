# PenguinCut 프로필 이미지

소셜 프로필 업로드용 800×800 PNG 3종입니다. `avatar-preview.png`에서 밝은 배경·어두운 배경·48px 크기를 한눈에 비교할 수 있습니다.

| 파일 | 구성 | 용도 |
| --- | --- | --- |
| `avatar-dark-800.png` | 네이비(#0f172a) 배경 + 흰 펭귄 | **프로필 업로드용 (권장)** |
| `avatar-light-800.png` | 흰 배경 + 네이비 펭귄 | 밝은 배경의 문서·PPT, 라이트 전용 프로필 |
| `avatar-transparent-800.png` | 투명 배경 + 네이비 펭귄 | 웹·영상 합성용. **프로필 업로드 금지** |
| `avatar-preview.png` | 3종 비교 시트 | 확인용 (업로드하지 않음) |

## 업로드

YouTube Studio → 맞춤설정 → 브랜딩 → 프로필 사진.

- 800×800 PNG, 4MB 이하 (현재 26KB)
- 프로필은 원형으로 잘리므로 로고를 중앙에 두고 가장자리를 비웁니다. 로고 최외곽 반경은 282px로, 프레임 반경 400px 안에 118px 여유를 둡니다.
- 같은 파일을 X(400×400), LinkedIn(400×400), GitHub(460×460), Google 계정(400×400)에 그대로 쓰면 됩니다. 플랫폼이 알아서 축소합니다.

## 투명 PNG를 쓰지 않는 이유

1. 업로드한 이미지는 플랫폼이 알파 채널을 **흰색 또는 검은색으로 평탄화**합니다. 어느 쪽으로 평탄화되는지는 플랫폼·테마·재인코딩 시점에 따라 다릅니다.
2. `avatar-transparent-800.png`의 투명 픽셀은 RGB(0,0,0)입니다. 검은 배경으로 평탄화되면 네이비 로고가 배경에 묻혀 **로고가 사라집니다**. `avatar-preview.png` 아래쪽 투명 칸이 그 상태입니다.
3. 원형 크롭과 만나면 배경 경계가 없어져 로고만 떠 보입니다.

`avatar-transparent-800.png`는 배경을 직접 고르는 사이트·영상·명함 작업에만 사용하세요.

## 만든 방법

`reportist-video/public/icon-512x512.png`의 펭귄 마크를 800×800 프레임 중앙에 가로 52% 크기로 배치하고, 배경만 네이비·흰색·투명으로 바꿔 3종을 만들었습니다. 로고 원본은 `reportist-video/public/penguin-logo.svg`입니다.
